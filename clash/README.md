# 로얄 아레나 (Royale Arena)

브라우저에서 돌아가는 카드 배틀 게임(바닐라 JS)입니다. 개인이 만든 팬 메이드 작품이며, 카드 일러스트는 사용자가 직접 제공한 이미지입니다. **상업적 배포는 하지 않습니다.**

## 실행 방법

- **가장 간단한 방법**: `index.html`을 브라우저로 직접 엽니다.
- **로컬 서버**: 이 폴더에서 `python3 -m http.server` 를 실행한 뒤 `http://localhost:8000` 에 접속합니다.
- **단일 파일 버전**: `node tools/build_standalone.mjs` 를 실행하면 `play.html` 이 만들어집니다. CSS, JS, 카드 이미지가 모두 들어 있어 이 파일 하나만 열면 됩니다.

## 조작법

- **카드 배치**: 손패의 카드를 선택한 뒤 아레나를 탭합니다. 또는 카드를 아레나까지 드래그합니다.
- **챔피언 능력**: 하단의 능력 버튼을 누릅니다. 엘릭서가 필요합니다.
- **이모티콘**: 💬 버튼으로 이모티콘 목록을 열고 보냅니다.
- **일시정지**: 상단 ⏸ 버튼. 계속하기 / 항복하기(연습 모드에서는 나가기)를 고를 수 있습니다. 탭을 숨기면 자동으로 일시정지됩니다.

## 게임 규칙 요약

- 아레나 크기: 18 x 32 타일, 가운데에 강이 있고 다리 2개가 있습니다.
- 타워: 진영마다 공주 타워 2개와 킹 타워 1개, 총 3개입니다.
- 엘릭서: 1.0 / 2.8초마다 1씩 차오르며 최대 10입니다. 시작값은 5입니다.
- 경기 시간: 3:00. 마지막 1:00 동안 엘릭서가 2배가 됩니다(연습 모드 제외).
- 연장전: 시간이 끝났는데 승부가 나지 않으면 1:00 연장전이 시작됩니다. 연장전에서는 엘릭서가 3배이며, 먼저 타워를 부수는 쪽이 이깁니다. 연장전에서도 결판이 나지 않으면 남은 타워 체력으로 승부를 가립니다.
- 킹 타워: 맞거나 공주 타워가 파괴되면 활성화됩니다.
- 왕관: 공주 타워 1개 = 왕관 1개입니다. 킹 타워를 부수면 왕관 3개로 즉시 승리합니다(트리 크라운). 시간 종료 시에는 왕관이 더 많은 쪽이 이깁니다.

## 모드

- **AI 대전**: 쉬움 / 보통 / 어려움 / 마스터 난이도가 있습니다.
- **연습 모드**: 무한 엘릭서, 시간 무제한, AI는 쉬움 난이도입니다.
- **Mod 모드**: 규칙과 카드 능력치를 바꾸거나 커스텀 카드를 만듭니다. 자세한 내용은 [MODDING.md](MODDING.md)를 참고하세요.

## 재화와 진행

- 상점에서 무료로 골드와 보석을 받을 수 있습니다.
- 모든 카드가 처음부터 열려 있어 원하는 카드로 덱을 구성할 수 있습니다.
- 카드 레벨은 1~16 중에서 고를 수 있습니다. 기본값은 11이며, AI도 같은 레벨로 맞춰집니다(설정에서 변경 가능).

## 파일 구조

```
index.html          진입점
css/                스타일 (main, shop, deck, mods)
js/
  data.js           카드, 타워, 규칙, 팩 데이터 (RA.BASE_CARDS, RA.RULE_DEFS, RA.BUILTIN_PACKS)
  cardtext.js       카드 설명 텍스트
  save.js           로컬 저장 (localStorage)
  audio.js          효과음
  mods.js           Mod 시스템 코어
  engine.js         전투 엔진 (Game 클래스)
  ai.js             AI 상대
  render.js         캔버스 렌더링
  ui*.js            화면 (홈, 상점, 덱, Mod, 전투)
  main.js           부트스트랩
assets/
  cards/            카드 일러스트 PNG (사용자 제공)
  portraits/        초상화 PNG
tools/
  sim.cjs                 헤드리스 밸런스/스모크 테스트
  build_standalone.mjs    play.html 단일 파일 빌드
```

## 테스트

```bash
node tools/sim.cjs [경기수]   # 기본 10경기, AI끼리 대전시켜 오류와 승패 분포를 출력
```

엔진을 브라우저 없이 돌려 보는 스모크 테스트입니다. 오류가 없고 경기가 끝나는지 확인할 때 사용합니다.

## 라이선스 및 주의

- 개인용 팬 메이드 프로젝트입니다. 원작의 상표, 일러스트, 음원 등은 저작권자에게 있습니다.
- 카드 일러스트는 사용자가 제공한 이미지이며, 이 저장소에서 재배포하거나 상업적으로 사용하지 마세요.


## 디자인 v2 / 아레나 가이드
- 타워·다리·강 좌표를 `아레나 배치 기준도`에 맞춰 조정(프린세스 y=23.5, 킹 y=29, 다리 x=4/14, 강 2타일).
- 석재 벽·돌길·다리·강 물결, 팀 링 유닛 토큰, 사망/등장 연출, 타워 파손 표현.
- 전투 중 📐 버튼: 4-3 / 3-3 건물 자리, 카이팅 타일, 출발 지점, 타워 사거리 오버레이.
