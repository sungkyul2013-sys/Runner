# SKY ACE: Horizon — AAA UI / 그래픽 / 모바일 조작 리디자인 계획

레퍼런스: 발로란트(각진 기하학, 플랫 패널, 대문자 콘덴스드 타이포, 날카로운 액센트 라인)와
GTA 6(풀블리드 시네마틱 배경, 석양 그라데이션, 큰 스택형 타이틀, 상단 탭 내비게이션)의 **디자인 문법만** 참고한다.
로고·폰트·아이콘·색상 코드 등 고유 자산은 복제하지 않는다.

## 1. 디자인 시스템

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | `#0A0D13` | 기본 배경, 패널 |
| `--bone` | `#ECE6DC` | 1차 텍스트(순백 대신 따뜻한 오프화이트) |
| `--ash` | `#8B93A1` | 보조 텍스트 |
| `--burn` | `#FF4B3A` | 1차 액센트(선택·CTA·경고) |
| `--dusk` | `#FF3D8B → #FF9A3D` | 석양 그라데이션(타이틀, 진행 바, 등급) |
| `--sky` | `#4FD8FF` | HUD·정보 액센트 |
| `--ok` | `#3DFFA8` | 성공 |

- **타이포**: 디스플레이 = Bebas Neue(라틴, 내장), 수치·HUD = Chakra Petch(내장), 한글 = 시스템 고딕 800–900 굵기.
  타이틀은 대문자 + 넓은 자간, 숫자는 tabular.
- **형태 언어**: 모서리를 45° 깎은 패널(`clip-path`), 1px 헤어라인, 좌측 4px 액센트 바, 인덱스 번호(`01 / 05`),
  사선 해칭 장식, 정사각 마커. 둥근 알약형 버튼은 사용하지 않는다(토글 제외).
- **깊이**: 블러 글래스는 HUD/인게임 오버레이에만, 메뉴는 불투명 잉크 패널 + 비네트 그라데이션으로 대비 확보.

## 2. 모션 시스템 (모든 애니메이션은 `transform`/`opacity`/`clip-path`만 사용 → 모바일 60fps)

| 이름 | 길이 / 이징 | 사용처 |
|---|---|---|
| `enter-stagger` | 420ms, `cubic-bezier(.16,1,.3,1)`, 항목당 45ms 지연 | 메뉴 항목, 카드 그리드 |
| `wipe` | 520ms 사선 슬래브(burn→ink) 화면 가로지름 | 화면 전환 |
| `bar-grow` | 260ms `scaleX 0→1` | 호버/포커스 액센트 바 |
| `slam` | 600ms scale 1.6→1 + blur 12→0 | MISSION COMPLETE/FAILED |
| `count-up` | 900ms easeOutExpo | 결과 수치, 점수 |
| `banner` | 180ms 진입 / 2.2s 유지 / 240ms 퇴장 | 킬 배너·토스트 |
| `letterbox` | 700ms 상하 시네마 바 + 미션 타이틀 카드 | 미션 시작 |
| `boot` | 로고 마스크 와이프 + 스캔라인 | 로딩 → 타이틀 |

`prefers-reduced-motion` 시 모두 페이드로 대체.

## 3. 정보 구조 & 반응형

- **가로(랜드스케이프)**: 좌측 대형 스택 메뉴(GTA식) + 우측 시네마틱 3D. 하위 화면은 상단 탭 바(언더라인 슬라이드).
- **세로(포트레이트)**: 상단 45% 3D 쇼케이스, 하단 시트형 콘텐츠, 하단 고정 탭 바(홈·캠페인·자유비행·격납고·설정), 썸 존 우선.
- 안전 영역(`env(safe-area-inset-*)`), 최소 터치 타깃 44px, 텍스트 최소 11px.
- 인게임 세로 모드: 카메라는 **수평 FOV 고정**(세로 화면에서 화면이 좁아지지 않게 수직 FOV 확장), HUD 테이프를 화면 중앙 쪽으로 압축,
  조작계는 하단 42% 영역에 배치.

## 4. 모바일 조작계 (AAA 모바일 슈터 문법)

- **플로팅 존**: 화면 좌/우 하단 존 어디를 눌러도 그 자리에 컨트롤이 생성(엄지 위치 적응). 놓으면 페이드아웃, 대기 중엔 희미한 힌트 글리프.
  - 분리형: 왼쪽 = 피치 전용 세로 캡슐, 오른쪽 = 롤 전용 가로 캡슐(축 하나만 반응 → 실수 입력 제거).
  - 가상 스틱: 오른쪽 존에 원형 스틱(데드존 링 + 방향 틱).
- **스로틀 레버**: 가장자리 슬림 레버, IDLE / MIL / AB 디텐트 눈금, 디텐트 통과 시 햅틱, 수치 판독.
- **버튼**: SVG 아이콘 원형 링 버튼. 주무장(GUN/MSL)은 크게 + 상태 링(락온 진행률·탄약). 
  **컨텍스트 버튼**만 노출: 기어(저고도/저속), 브레이크(지상), 훅(훅 장착기), 캐터펄트(갑판 대기), 플랩은 소형 스테퍼.
- 상단은 우측 코너 아이콘 3개(일시정지·카메라·오토파일럿)만, 나머지는 “더보기” 서랍.
- 눌림 피드백: 스케일 0.92 + 링 펄스 + 8ms 진동.

## 5. 월드 그래픽

- **도심 = 실제 서울 OSM 데이터**: 강남·송파(삼성동 COEX ~ 잠실 롯데월드타워) 건물 5,159동의 실제 외곽선·높이(롯데월드타워 554m),
  한강·석촌호수 수면, 공원 251개, 도로 1,823개를 사용. 출처 표기: © OpenStreetMap contributors (ODbL).
  - 높이 태그 없는 건물: 용도·면적 기반 결정론적 추정(아파트 단지 고층화).
  - 렌더링: 단일 병합 지오메트리 + 건물 ID 속성 + 상태 텍스처 → 붕괴 애니메이션을 버텍스 셰이더에서 처리(드로콜 1).
  - 파사드: 층 높이 3.4m 창문 그리드, 고층(>80m)은 커튼월 반사 유리, 야간 창문 조명 랜덤 점등, 옥상 색 분리.
  - 도로: 폭(등급별) 쿼드 + 중앙선, 간선도로 가로등(야간 블룸), 한강은 해양 셰이더 공유.
- 지형: 암벽 트라이플래너 + 층리, 원거리 매크로 변화, 해안 거품, 침엽/활엽 수목.

## 6. 구현 순서 & 검증

1. OSM 추출기(`scripts/extract_seoul.py`) → `assets/seoulData.ts` (int16, 185KB)
2. `world/City.ts` 재작성(실데이터, 셰이더 붕괴, 수면·공원·도로·가로등)
3. 폰트 내장 + `ui/styles.ts` 디자인 토큰/모션 재작성
4. `ui/Menus.ts` 재구성(가로/세로, 전환 와이프, 탭, 결과 연출, 킬 배너, 레터박스)
5. `core/Input.ts` 터치 조작 재작성(플로팅 존, 레버 디텐트, 아이콘 버튼, 컨텍스트 노출)
6. HUD/카메라 세로 대응
7. 검증: 물리 회귀(`simTest`), 미션 자동 테스트, 가로·세로 폰 스크린샷
