# 수 국어논술 — 국어의 감각을 설계하다

학원 소개부터 진단 평가 · 문제 풀이 · 개념 학습 · 어휘 · 독해 · 논술 · 학습 루틴까지,
국어 학습의 전 과정을 담은 3D 반응형 웹 앱입니다.

**모바일 게임 형태의 앱**입니다. 상단 HUD(레벨·XP·코인·연속일)와 하단 5탭 바 사이에서
화면이 흐르고, 학습은 3D 스테이지 맵의 돌을 하나씩 넘는 방식으로 진행됩니다.

Vite + TypeScript + Three.js. 프레임워크 없이 순수 DOM으로 구현했고,
서버·계정·네트워크 요청이 전혀 없습니다. 학습 기록은 브라우저 localStorage에만 저장됩니다.

디자인은 「단청 위의 먹」 — 먹빛 바탕에 단청 안료(황·장단·뇌록·삼청·자주)를 얹었고,
버튼은 눌리는 깊이를 가진 3D 형태입니다. 밝은 테마는 한지 바탕입니다.
전면에 종이 그레인을 깔고, 타이틀은 금박 압인(押印) 처리, 구분선은 단청 연화 문양입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc --noEmit + 프로덕션 번들
npm run preview  # 빌드 결과 미리보기
```

이 저장소는 멀티 페이지로 구성되어 있습니다.

| 진입점 | 내용 |
| --- | --- |
| `index.html` | **수 국어논술** 학습 앱 |
| `runner.html` | 기존 NeonDash 3D 엔들리스 러너 |

`npm run build:app` 을 실행하면 JS·CSS를 전부 인라인한 단일 파일 `soo-korean.html`
(약 1MB)이 만들어집니다. 네트워크 요청이 0건이라 파일 하나만 열어도 그대로 동작합니다.

## 기능

### 3분 체험 — 처음 오신 분의 첫 화면
첫 방문자에게는 표지의 기본 버튼이 **「3분 체험 시작」**이 됩니다. 설명 대신
수 국어논술의 한 학기 흐름을 그대로 한 바퀴 겪게 하는 안내 코스입니다.

| 단계 | 내용 |
| --- | --- |
| 환영 | 학원 소개와 코스 안내 |
| 진단 | 6문항 · 여섯 역량을 하나씩 |
| 리포트 | 레이더 + 밴드 + 먼저 다질 영역 (만점이면 문구가 달라집니다) |
| 수업 | 약한 영역의 개념 카드(함정 포함) → 즉시 해설 문항 3개 |
| 어휘 | 간격 반복 카드 한 장을 실제로 넘기고 등록 |
| 루틴 | 요일·시간을 고르면 진단 결과를 반영한 주간 계획 생성 |
| 완료 | 무엇을 했는지 대장(臺帳), 오늘 할 일, 열린 기능 목록 |

체험은 시연이 아닙니다. 여기서 푼 문항 · 진단 결과 · 어휘 카드 · 루틴이
모두 실제 프로필에 저장되어 곧바로 이어집니다. 언제든 건너뛸 수 있습니다.

### 시작 화면 → 스크롤 → 상담 신청
- 첫 화면은 **게임 시작 화면**입니다. 금박 타이틀, 금 실선 표지 프레임과 모서리 장식,
  세로쓰기 `讀 · 論 · 述` 레일, 낙관(落款) 인장, 그 뒤로 도는 3D 글자 구름.
- 아래로 내리면 학원 소개가 애플식 편집 리듬으로 이어집니다 — 하이라인으로 나눈 숫자,
  단청 연화 오너먼트 구분선, 방법론 · 커리큘럼 · 프로세스 · 강사진 · 후기 · FAQ.
- 마지막은 **상담 신청 양식**입니다. 이름·학년·연락처·관심 트랙·희망 시간·고민을 받아
  신청서를 만들어 줍니다. 서버가 없으므로 전송하는 척하지 않고, 브라우저에 저장한 뒤
  복사 · 전화 · 메일 링크를 제공합니다.

### 3D 스테이지 맵 (게임 진행)
- 28개 스테이지가 잉크 공간을 가로지르는 길 위의 **돌**로 놓입니다. 드래그로 길을 이동하고,
  돌을 탭하면 그 단계로 들어갑니다. 다음에 열린 돌은 맥동해 항상 다음 수가 분명합니다.
- 정답률에 따라 별 1~3개(총 84개), 별을 얻어야 다음 돌이 열립니다. 5의 배수 단계는 **관문**입니다.
- 단계마다 **보너스 목표**가 따로 있습니다 — 무실수 / n연속 정답 / 문항당 평균 시간.
- **일일 과제** 3종이 매일 새로 배정됩니다(날짜 기반 고정 시드). 전부 끝내면 추가 보상.
- 연속 정답 콤보(최대 2배 XP), 떠오르는 +XP, 오답 시 화면 흔들림, 레벨 업 연출.

### 콘텐츠
- 문항 **162개** — 각 문항에 해설, 일부는 선택지별 오답 노트 포함.
- 지문 **18편** — 비문학 8편은 창작, 문학 10편은 저작권 보호 기간이 만료된 작품
  (김소월 · 이육사 · 정지용 · 윤동주 · 이상 · 현진건 · 황진이 · 청산별곡 · 윤선도).
- 개념 카드 20장 · 어휘 63개 · 맞춤법 36쌍 · 논술 논제 5개 · 뱃지 24종.

## 접근성 · 성능
- 시스템/수동 다크 모드, `prefers-reduced-motion` 및 앱 내 모션 축소 설정 지원
  (켜면 3D 애니메이션과 등장 효과가 멈춥니다).
- WebGL을 못 쓰는 환경에서는 스테이지 맵이 목록으로 대체됩니다.
- 3D 품질 `가볍게` 옵션, 화면 크기별 타일 수 조절, DPR 클램프,
  탭이 백그라운드로 가면 렌더 루프 정지.
- 키보드: 문항 선택 `1`~`5`, 다음 문제 `Enter`, 화면 이동 `H M P T G`.
