# 수 국어논술 — 국어의 감각을 설계하다

학원 소개부터 진단 평가 · 문제 풀이 · 개념 학습 · 어휘 · 독해 · 논술 · 학습 루틴까지,
국어 학습의 전 과정을 담은 3D 반응형 웹 앱입니다.

**모바일 게임 형태의 앱**입니다. 상단 HUD(레벨·XP·코인·연속일)와 하단 5탭 바 사이에서
화면이 흐르고, 학습은 3D 스테이지 맵의 돌을 하나씩 넘는 방식으로 진행됩니다.

Vite + TypeScript + Three.js. 프레임워크 없이 순수 DOM으로 구현했고,
서버·계정·네트워크 요청이 전혀 없습니다. 학습 기록은 브라우저 localStorage에만 저장됩니다.

디자인은 「단청 위의 먹」 — 먹빛 바탕에 단청 안료(황·장단·뇌록·삼청·자주)를 얹었고,
버튼은 눌리는 깊이를 가진 3D 형태입니다. 밝은 테마는 한지 바탕입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc --noEmit + 프로덕션 번들
npm run preview  # 빌드 결과 미리보기
```

이 저장소는 멀티 페이지로 구성되어 있습니다.

| 진입점 | 내용 |
| --- | --- |
| `index.html` | **수 국어논술** 학습 앱 |
| `runner.html` | 기존 NeonDash 3D 엔들리스 러너 |

`npm run build:app` 을 실행하면 JS·CSS를 전부 인라인한 단일 파일 `soo-korean.html`
(약 930KB)이 만들어집니다. 네트워크 요청이 0건이라 파일 하나만 열어도 그대로 동작합니다.

## 기능

### 3D 스테이지 맵 (게임 진행)
- 20개 스테이지가 잉크 공간을 가로지르는 길 위의 **돌**로 놓입니다. 드래그로 길을 이동하고,
  돌을 탭하면 그 단계로 들어갑니다. 다음에 열린 돌은 맥동해 항상 다음 수가 분명합니다.
- 정답률에 따라 별 1~3개, 별을 얻어야 다음 돌이 열립니다. 5·10·15·20단계는 **관문**입니다.
- 연속 정답 콤보(최대 2배 XP), 떠오르는 +XP, 오답 시 화면 흔들림, 레벨 업 연출.

### 학원 소개 (홈 · 타이틀 화면)
- Three.js로 만든 3D 글자 타일 클라우드 히어로 — 포인터로 시점이 따라오고,
  스크롤하면 카메라가 글자 사이를 통과합니다. 모바일에서는 기기 기울기에도 반응합니다.
- 스티커 형태의 워드마크, 무한 마퀴, 교육 철학 4단계 카드,
  단계별 등장 애니메이션, 숫자 카운트업.
- 커리큘럼 6개 트랙 · 강사진 · 수업 프로세스 · 후기 · FAQ · 오시는 길.

### 콘텐츠
- 문항 **128개** — 비문학 27 · 문학 25 · 문법 42 · 어휘 19 · 논술 15,
  각 문항에 해설과 일부는 선택지별 오답 노트 포함.
- 지문 **14편** — 비문학 6편은 창작, 문학 8편은 저작권 보호 기간이 만료된 작품
  (김소월 · 이육사 · 정지용 · 윤동주 · 현진건 · 황진이 · 청산별곡 · 윤선도).
- 개념 카드 20장 · 어휘 63개 · 맞춤법 36쌍 · 논술 논제 5개 · 뱃지 24종.

## 접근성 · 성능
- 시스템/수동 다크 모드, `prefers-reduced-motion` 및 앱 내 모션 축소 설정 지원
  (켜면 3D 애니메이션과 등장 효과가 멈춥니다).
- WebGL을 못 쓰는 환경에서는 스테이지 맵이 목록으로 대체됩니다.
- 3D 품질 `가볍게` 옵션, 화면 크기별 타일 수 조절, DPR 클램프,
  탭이 백그라운드로 가면 렌더 루프 정지.
- 키보드: 문항 선택 `1`~`5`, 다음 문제 `Enter`, 화면 이동 `H M P T G`.
