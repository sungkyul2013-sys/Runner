# 수 국어논술 학원 — 3D 웹사이트

`index.html` + `site/`에 있는 학원 소개 사이트입니다. Vite + TypeScript +
Three.js로 만든 **스크롤 구동형 3D 원페이지**이며, 별도 프레임워크·CDN·폰트
요청 없이 자체 번들만으로 동작합니다.

> 이 저장소는 원래 게임(Sunset Runner) 저장소입니다. 게임은 `game.html`로
> 그대로 남아 있고(`npm run dev` 후 `/game.html`), 루트 `index.html`이 학원
> 사이트가 됩니다. 두 페이지 모두 한 번의 `npm run build`로 빌드됩니다.

## 실행

```bash
npm install
npm run dev            # http://localhost:5173  (게임은 /game.html)
npm run build          # tsc --noEmit + vite build → dist/
npm run preview        # 빌드 결과 확인
npm run build:site     # → su-academy.html (단일 파일, 의존성 0)
```

`build:site`는 `index.html` + `site/`를 Three.js와 스타일까지 통째로 인라인해
**su-academy.html 한 파일**로 만듭니다. 정적 호스팅에 그대로 올리거나 파일을
더블클릭해서 열어도 외부 요청 없이 동작합니다. `--artifact <path>`를 주면
`<html>/<head>/<body>`를 자기가 감싸는 호스트용으로 래퍼 없는 사본도
함께 씁니다(`--title`로 제목 교체 가능).

## 3D 구조 (`site/three/`)

- **`shapes.ts`** — 형상별 포인트 클라우드 생성기. `수` 글자는 오프스크린
  캔버스에 렌더한 뒤 채워진 픽셀을 샘플링해서 만듭니다(폰트 메시 불필요).
  모든 형상은 같은 개수의 점을 같은 크기 범위로 반환하므로 어떤 조합으로도
  모핑할 수 있습니다.
- **`Field.ts`** — 주인공. 각 점이 출발 좌표(`position`)와 도착
  좌표(`aTo`), 시드를 들고 있고 셰이더에서 보간합니다. 시드로 출발 시점을
  흩뿌려서 구름이 풀렸다가 다시 뭉치듯 보입니다. 모핑 도중에 다음 형상이
  요청되면 셰이더와 **동일한 수식으로** 현재 좌표를 CPU에서 스냅샷해
  이어가므로 튀는 현상이 없습니다.
- **`Sheets.ts`** — 뒤쪽 깊이감을 만드는 종이들.
- **`Scene.ts`** — 렌더러/카메라/루프. 좁은 화면에서는 씬 전체를 축소하고,
  파티클 불투명도를 낮춰 본문 가독성을 지킵니다.

성능: DPR 2 제한, 모바일에서 점 개수 4,200(데스크톱 9,500), 탭이 숨겨지면
정지, 그리고 **투명 섹션이 화면에 하나도 없으면 렌더 루프 자체를 멈춥니다**
(밝은 섹션에서는 캔버스가 보이지 않으므로).

## 인터랙션 (`site/ui/`)

- `scroll.ts` — 스크롤 구동 효과 전부가 공유하는 단일 rAF 루프.
- `nav.ts` — 고정 헤더(스크롤 다운 시 숨김), 모바일 시트, 앵커 이동,
  진행 바, 활성 링크, 하단 독.
- `motion.ts` — 등장 애니메이션, 헤드라인 글자 분해, 매니페스토 단어
  하이라이트, 숫자 카운터, 카드 틸트.
- `rail.ts` — 과정 섹션 가로 스크롤, 후기 마퀴.
- `form.ts` — 상담 폼 검증/전화번호 포맷/토스트, FAQ 아코디언.

접근성/폴백: `prefers-reduced-motion`을 존중하고, WebGL을 못 쓰면 CSS
그라디언트 배경으로 대체되며, JS가 실행되기 전에는 아무것도 숨기지 않습니다
(`.js` 클래스가 붙어야 등장 애니메이션이 활성화됨).

## 교체해야 할 내용

**페이지의 학원 정보는 전부 예시 데이터입니다.** 실제 사용 전에 아래를
바꾸세요.

- 주소·전화·이메일·상담 시간 (`index.html`의 `#visit` 섹션, 헤더/독의
  `tel:` 링크)
- 성과 수치 (`data-count` 속성 4개)
- 선생님 이름·경력, 후기 문구
- 상담 폼은 **전송되지 않습니다.** 백엔드나 폼 서비스에 연결하려면
  `site/ui/form.ts`의 submit 핸들러에서 `fetch`를 붙이면 됩니다.
