# APEX_SIM 로드맵 (v0.2 — 승인됨, 연속 진행)

> §22 로드맵의 마일스톤 순서와 완료 조건을 그대로 따르고, 웹 버전(KICKOFF 결정 사항) 기준의 구체 작업과 측정 가능한 합격 기준을 붙였다.
> 진행 현황: **M0 완료** ([보고서](docs/reports/M0.md)) · **M1 완료** ([보고서](docs/reports/M1.md), 최고속·입력 링·핫리로드는 이월) · **M2 완료** ([보고서](docs/reports/M2.md)) · M3 다음
> 규모 표기: S < M < L < XL (상대 규모. M0 = M 기준).

## 공통 완료 조건 (모든 마일스톤, §2.2 · §2.3 · §2.5 · §2.8)

1. 실행 가능한 빌드(`npm run build`) + 실행 방법이 적힌 README.md
2. 자동 테스트 전부 통과(코어 네이티브·WASM, 웹, E2E)
3. 스크린샷(Playwright 자동 캡처) 또는 짧은 영상
4. 변경 요약(CHANGELOG.md), 알려진 문제(KNOWN_ISSUES.md), 다음 계획
5. REQUIREMENTS.md 상태 갱신(미착수 → 진행 → 완료 → 검증됨)
6. 벤치 결과 JSON(`bench/results/Mx-*.json`): 프레임 시간, 물리 스텝 시간, RTF, 메모리
7. 기존 동작을 바꾼 경우 골든 리플레이 해시 비교 통과. 의도적으로 바뀐 경우 해시 갱신 사유를 기록한다

## M1 첫 주행 — 사용자 포르쉐 911 터보

사용자 지정(KICKOFF 결정 사항 Q6)에 따라 첫 차량은 파라메트릭 세단 대신 **사용자의 포르쉐 911 터보(2014, 991) 모델**을 쓴다. 롤스로이스 고스트와 마이바흐 GLS는 같은 생성기로 M1 후반~M2에 추가한다.

- 사용자 모델 가져오기: Crash Lab 베이크 데이터(`Runner` 브랜치 `claude/game-development-ba0ut4`) → 실측 치수 정규화 → 도색·유리·램프 재질 분리 → glTF(양자화) 교체 슬롯.
- 차량 데이터 포맷 v1(`docs/VEHICLE_FORMAT.md`), C++ 로더(yyjson), 데이터 핫리로드, 실시간 입력 링(SPSC SAB).
- 빔 종류 추가: anisotropic, hydro(조향 랙). 삼각형·압력 그룹.
- 차체 생성기: 모델 외형(선체 샘플링)에 맞춘 노드-빔 모노코크 + 실제 링크 지오메트리 서스펜션(앞 맥퍼슨, 뒤 멀티링크).
- 하이브리드 타이어(압력 휠 + Magic Formula + 완화 길이, 구름 저항).
- 파워트레인: 3.8 L 수평대향 6기통 토크 곡선(과급 동특성은 M8), 플라이휠 관성, 엔진 브레이크, 아이들, 레브 리미터, 클러치(stick-slip), 7단 변속 + 자동 클러치, AWD(센터 커플링), 구동축 비틀림.
- 브레이크(디스크 토크, 전후 배분, ABS), 조향(기어비, 최대 조향각).
- 키보드·게임패드 입력 + 기본 보조(조향 스무딩·속도 감응), 추적 카메라, 사용자 모델을 노드에 바인딩해 표시(GPU flexbody 전체 변형은 M2).
- **합격:** 차량 `targets`(0-100 km/h, 제동거리, 최고속도) 대비 ±5%, 스키드패드 0.95~1.1 g(스포츠카), 코스트다운 역산 항력·구름 저항 ±5%, 평지 10분 정지 안정, 30% 경사 브레이크 정지 유지.

## M2 충돌·파손

- 차↔차 노드↔삼각형 + 모서리↔모서리, 자기충돌, 정적 월드 BVH(셀 단위 스트리밍은 M6), 전체 CCD(KICKOFF C2 정의).
- 소성변형 누적, 파단, breakGroup 연쇄, 연결 성분 분리 → 독립 섬, 분리 부품 충돌.
- Flexbody GPU 변형(WebGPU 컴퓨트 + WebGL2 폴백), 노멀 재계산, 찢어짐 경계.
- 유리: 접합유리(거미줄 균열·처짐), 강화유리(알갱이 파편 파티클). 라이트 파손.
- 손상→기능 연동 1차: 냉각·오일·연료·조향·서스펜션 얼라인먼트·구동계·브레이크 라인·래치.
- 발사 도구(속도·방향), 두 차량 자동 충돌 설정기, 충돌 이벤트 로그, 에너지·운동량 디버그 그래프.
- (REQUIREMENTS 배정) 노드 잡기·크레인·윈치(§20), 타이어 펑크·블로우아웃·비드 이탈·림 주행·림 손상(§6), 삼각형 공력·다운포스·슬립스트림(§10).
- **합격:** 64 km/h 고정벽·차대차 충돌 재현, 에너지 수지 < 5%(KICKOFF C3), 운동량 < 1%, 300 km/h 이상·얇은 벽 무작위 1,000회 관통 0회, 10대 동시 충돌 벤치 측정 → **KICKOFF Q3 재논의**.

## M3 노면·테스트

- §11.1 재질 표 전체(`data/surfaces/`), µ-split, 미세 요철 함수, 변형 층(자갈·진흙·모래·눈), 수막현상, 타이어 열·마모·종류.
- M1·M2에서 이월: 트레드 링 반경 자유도의 암시 적분(최고속 목표, KNOWN_ISSUES P16), 롤스로이스 고스트·마이바흐 GLS 물리 차량(생성기, W9), 입력 링·핫리로드(W6).
- §11.3 도로 시설 프리팹 전부(국내 방지턱 규격, 불량 방지턱, 럼블 스트립, 연석 3종, 포트홀, 맨홀, 그레이팅, 철도 건널목 등), `docs/SURFACE_FORMAT.md`.
- §12.1~12.5 셰이커 리그(4포스트), K&C, RTI 램프, 드롭 테스트, 범프·승차감 코스(ISO 8608 A~H 노면 생성).
- §12.8 텔레메트리(도킹 패널, CSV 내보내기), §12.9 셋업 에디터(간단/전문가, A/B).
- 무한 그리드맵 확장, 도시 인프라 테스트 스트리트(§13.3-7). X-ray·슬로모션 관찰.
- **합격:** 방지턱 3.6 m × 10 cm에서 20~30 km/h 부드럽게, 50 km/h 이상 강한 충격·범프스탑 접촉 가능, 고속에서 순간 이륙(트래블·가속도 로그), 자갈 제동거리가 건조 아스팔트의 1.5~2배, 셰이커 스프렁 고유진동수가 쿼터카 이론값 ±10%, 노면별 제동거리가 d = v²/(2µg) 경향을 따름.
