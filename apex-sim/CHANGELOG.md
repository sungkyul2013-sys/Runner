# 변경 이력

## M1 — 첫 주행 (진행 중)

### 추가
- **M1a 요소**: 비등방 빔(압축·인장 강성 분리), hydro 빔(입력 채널 + 속도 제한), 슬라이더(노드-레일), 등온 압력 그룹(발산 정리 부피, 기체 위치에너지 계상), 토션 바(반력을 레버 발끝에 걸어 순수 우력), 결정론 `det::atan2` — 테스트 5종
- **M1b 차량 서브시스템** (`sbc/vehicle.h`): 하이브리드 타이어(노드 타이어 + 과도 슬립 Magic Formula), 엔진·자동 클러치·DCT형 변속기(자동/수동 시퀀셜)·구동계 와인드업·LSD, stick-slip 브레이크·핸드브레이크, ABS·TCS, hydro 조향, 차체 항력·다운포스, 텔레메트리. 차량 힘의 일은 에너지 원장에 외부 일·마찰로 정확히 계상
- 압력 휠 생성기(`addPressureWheel`), 절차 생성 기준차 **APEX Proto**(격자 차체, 4륜 더블 위시본, 안티롤바, 코일오버·범프스톱, 랙 조향, 1.19 t FR), `proto_drive` 씬, C ABI 차량 함수 6종
- 재질 쌍: 고무↔아스팔트·콘크리트·강철, 강철↔아스팔트(§11.1). `ContactPairParams`에 구름저항·트레드 하중 분담 추가
- **M1c 차량 데이터**: `apex-vehicle` JSON 포맷(docs/VEHICLE_FORMAT.md)과 코어 로더(yyjson, 결정론 파싱, JSON 경로를 담은 오류), C ABI `sbc_world_spawn_vehicle_json`, `sbc-cli vehicle`(안정성·정착·하중 분배 보고)
- **포르쉐 911 터보(991) 생성기** (`tools/vehicle-gen`): GLB 차체 헐로 자른 격자 섀시, 맥퍼슨 스트럿(슬라이더 톱 마운트)·5링크 후륜, 조향 고정 기구학 풀이로 구한 범프 스티어 0 타이로드·토 링크 점, 승차 주파수 스프링, 1,595 kg·앞 39 % 질량 풀이, 7단 PDK·AWD 30/70·후륜 LSD → 799 노드·5,846 빔, 안정성 통과, 정착 후 앞 하중 39.0 %
- 차량 테스트 8종: 안정성, 정지 유지, 30% 경사 핸드브레이크, 100→0 km/h ABS 제동(41~43 m, 직진), TCS 발진, 코스트다운 에너지 수지, 조향 방향, 스레드 수 무관 결정론. 네이티브·WASM 해시 일치
- **M1d 튜닝·§23.2 시험(포르쉐)**: 100→0 km/h 35.1 m, 0→100 km/h 3.31 s(목표 3.4 s), 정상 스키드패드(R 30.5 m) 0.98 g, 코스트다운 99→80 km/h 19.6 s(도로 부하 모델 19.5 s), 30% 경사 5초 밀림 0.1 mm, 200 km/h대 휠 홉 없음 — 테스트 6종 추가(`[porsche]`)
- 능동 센터 커플링(`centreCoupling`, PTM/할덱스형 다판 클러치: 뒤 차축 직결, 앞 차축 몫이 축 하중을 따르고 토크는 빠른 쪽에서 느린 쪽으로만 흐름)
- TCS 피드포워드를 "가장 먼저 한계에 닿는 구동 바퀴" 기준으로 바꾸고, 슬립 적분 보정이 한계가 실제로 걸릴 때만 1.5배까지 올라가게 함
- 타이어 반경 스프링(`verticalStiffness`, `radialDamping`): 허브 높이로 처짐을 재고 허브에 건다. 스포크 강성(`spokeStiffness`)을 림 링과 분리
- 포르쉐 생성기: 서브프레임, 차축 뒤 토 링크, 수평 하부 암·작은 킹핀 오프셋의 맥퍼슨, 타이어 µ 1.18, 무거운 허브 노드, 트레드 접촉 구 5 cm

### 변경
- 고무↔아스팔트 명시 구름저항 0.010 → 0.0097, 고무↔콘크리트 0.009 → 0.0092(트레드 자체 손실을 합쳐 25 m/s에서 약 0.012). 저속 구름저항 모멘트의 정칙화 구간 0.3 → 0.05 m/s
- APEX Proto: 하드포인트 결속 3e5 → 6e5 N/m(질량 2 kg). 핸드브레이크 경사 시험은 착지 흔들림이 가라앉은 4초 뒤부터 잰다

### 수정
- 고속(약 210 km/h 이상)에서 네 바퀴가 같은 위상으로 10 Hz 홉을 일으키던 문제. 원인은 반경 스프링이 링 질량 중심의 높이를 쟀던 것(접지면이 눌리면 질량 중심이 올라가 스프링이 눌릴수록 약해짐)
- 고속 휠 부풂(스포크 1e5 N/m로 림이 300 km/h에서 2.6 cm 성장) → 최고속 233 → 약 290 km/h(KNOWN_ISSUES P16)
- 앞바퀴 구동력에 의한 차체 재킹·3 Hz 피치 한계 사이클(하부 암 처짐 12°, 킹핀 오프셋 11 cm)
- 후륜 토 플러터(토 링크가 차축 앞에 있어 컴플라이언스 스티어가 불안정), 하드포인트·격자 컴플라이언스

### 해결
- KNOWN_ISSUES P8(비등방·hydro·압력 그룹 없음) — M1a에서 구현
