# 변경 이력

## M1 — 첫 주행 (진행 중)

### 추가
- **M1a 요소**: 비등방 빔(압축·인장 강성 분리), hydro 빔(입력 채널 + 속도 제한), 슬라이더(노드-레일), 등온 압력 그룹(발산 정리 부피, 기체 위치에너지 계상), 토션 바(반력을 레버 발끝에 걸어 순수 우력), 결정론 `det::atan2` — 테스트 5종
- **M1b 차량 서브시스템** (`sbc/vehicle.h`): 하이브리드 타이어(노드 타이어 + 과도 슬립 Magic Formula), 엔진·자동 클러치·DCT형 변속기(자동/수동 시퀀셜)·구동계 와인드업·LSD, stick-slip 브레이크·핸드브레이크, ABS·TCS, hydro 조향, 차체 항력·다운포스, 텔레메트리. 차량 힘의 일은 에너지 원장에 외부 일·마찰로 정확히 계상
- 압력 휠 생성기(`addPressureWheel`), 절차 생성 기준차 **APEX Proto**(격자 차체, 4륜 더블 위시본, 안티롤바, 코일오버·범프스톱, 랙 조향, 1.19 t FR), `proto_drive` 씬, C ABI 차량 함수 6종
- 재질 쌍: 고무↔아스팔트·콘크리트·강철, 강철↔아스팔트(§11.1). `ContactPairParams`에 구름저항·트레드 하중 분담 추가
- **M1c 차량 데이터**: `apex-vehicle` JSON 포맷(docs/VEHICLE_FORMAT.md)과 코어 로더(yyjson, 결정론 파싱, JSON 경로를 담은 오류), C ABI `sbc_world_spawn_vehicle_json`, `sbc-cli vehicle`(안정성·정착·하중 분배 보고)
- **포르쉐 911 터보(991) 생성기** (`tools/vehicle-gen`): GLB 차체 헐로 자른 격자 섀시, 맥퍼슨 스트럿(슬라이더 톱 마운트)·5링크 후륜, 조향 고정 기구학 풀이로 구한 범프 스티어 0 타이로드·토 링크 점, 승차 주파수 스프링, 1,595 kg·앞 39 % 질량 풀이, 7단 PDK·AWD 30/70·후륜 LSD → 799 노드·5,846 빔, 안정성 통과, 정착 후 앞 하중 39.0 %
- 차량 테스트 8종: 안정성, 정지 유지, 30% 경사 핸드브레이크, 100→0 km/h ABS 제동(41~43 m, 직진), TCS 발진, 코스트다운 에너지 수지, 조향 방향, 스레드 수 무관 결정론. 네이티브·WASM 해시 일치

## M0 — 기반 (2026-09-23)

### 추가
- **SoftBodyCore (C++20)**: SoA 노드·빔(normal·support·bounded·rope), symplectic Euler 2000 Hz, 경화를 포함한 소성 복귀 사상, 파단 힘·변형 한계·breakGroup
- 접촉: 질량 비례 페널티 스프링-댐퍼 + stick-anchor 쿨롱 마찰(정지/운동 분리, 변위 기반 앵커) — 지면 평면, 정적 삼각형 메시, 노드 구 바디↔바디. 정적 표면 CCD
- 계측: 운동·중력·빔·접촉 위치에너지, 빔 감쇠·접촉 감쇠·마찰·소성·파단·CCD 손실, 외부 일 → 에너지 수지. 선·각운동량. FNV-1a 상태 해시
- 결정론: 고정 순서 병렬(섬 단위 fork-join), 자체 sin/cos, FMA 축약 금지, 바디별 double 원점 + 4 m 재기준
- 안정성 검사기(감쇠 보정 빔 조건 + Gershgorin 노드 조건), 격자 구조물 생성기, 기준 씬 6종, `sbc-cli`(run·bench·stability·golden), C ABI
- 테스트 30종(Catch2): §23.1 자유낙하·진동 주기·감쇠 진동·운동량·결정론(10회, 1·2·4 스레드, 골든 해시)·10분 정지·30% 경사 정지·안정성 한계·64 km/h 에너지 수지·빔·CCD — 네이티브와 WASM 모두 통과
- **웹**: 물리 워커(WASM SIMD128 + pthreads), SharedArrayBuffer 락프리 트리플 버퍼, 프레임 보간, 과부하 시 슬로다운(RTF 표시), 시간 제어(일시정지·한 스텝·1/2~1/100)
