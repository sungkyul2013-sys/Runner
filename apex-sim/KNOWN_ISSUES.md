# 알려진 문제·미구현 (§1.8)

"구현된 척 금지" 원칙에 따라 임시 구현, 제약, 미구현 항목을 모두 여기에 적는다. 해결되면 항목을 지우고 CHANGELOG.md에 기록한다.

## 물리 코어

| # | 내용 | 영향 | 계획 |
|---|---|---|---|
| P1 | 바디↔바디 충돌은 **노드 구↔노드 구** 페널티만 구현했다(노드↔삼각형, 모서리↔모서리 없음). 노드 간격보다 반경이 작으면 고속 충돌 때 격자끼리 일부 파고든다. M0 큐브는 반경을 격자 간격의 절반 가까이(0.1 m / 0.25 m)로 잡아 완화했다 | 차↔차 충돌 품질 | M2: 노드↔삼각형 + 모서리↔모서리 + CCD (§5.2) |
| P2 | 마찰을 노드 중심(점질량)에 가하므로, 실제 접촉점과의 거리(접촉 반경)만큼 가짜 우력이 생긴다. **마찰이 있는 바디↔바디 충돌에서는 각운동량이 보존되지 않는다**(시험 장면에서 약 20%). 선운동량은 1e-7 수준으로 보존되고, 마찰이 없으면 각운동량도 1% 이내로 보존된다(테스트로 확인) | §5.3 각운동량 보존 | M2: 노드↔삼각형 접촉으로 팔 길이를 노드 반경 수준으로 축소. 잔여량은 측정해 재보고 |
| P3 | 빔이 끊어져도 **연결 성분 분리(독립 섬)는 하지 않는다**. 떨어진 조각은 같은 바디로 남고 자기충돌이 없어 서로 통과한다 | 파손 연출 | M2 (§4.3 분리 부품) |
| P4 | 정적 삼각형 광역 단계가 **선형 탐색**이다(바디마다 전체 정적 삼각형 AABB 검사) | 대형 맵 성능 | M3/M6: 셀 단위 BVH + 스트리밍 (A§4.6) |
| P5 | float32 좌표의 한계 때문에 노드가 스텝당 ½ ulp보다 적게 움직이면 위치가 멈춘 채 **잔여 속도**가 남는다. 상한은 ulp(x)/(2·dt)이다. 4 m 재기준(rebase)으로 좌표를 작게 유지해 자동차 크기 바디에서는 약 0.5 mm/s 이하로 묶었다 | 정지 차량 텔레메트리의 미세 속도 | 필요하면 보상 합산(Kahan) 위치 적분 검토 |
| P6 | 페널티 접촉이 시작되는 스텝의 적분 오차 때문에 큰 충격 1회당 충격 에너지의 약 1%가 수지 오차로 남는다(큐브 낙하 0.96%, 64 km/h 크래시 0.34%, 합격선 5%) | 에너지 수지 정밀도 | 접촉 시점 보간 검토 (M2) |
| P7 | 빔 커널이 아직 **스칼라 코드**다(수작업 SIMD 아님) | 성능 여유 | M2 크래시 벤치 이후 SIMD128/AVX2 커널 |
| P8 | 빔 종류 중 anisotropic, hydro, 삼각형 압력 그룹은 아직 없다 | 타이어·조향 | M1 |
| P9 | 공기 저항이 없다 | 고속 주행 | M2 (§10 삼각형 공력) |

## 웹 클라이언트

| # | 내용 | 영향 | 계획 |
|---|---|---|---|
| W1 | 이 개발 컨테이너의 헤드리스 Chromium 141(SwiftShader)에서는 **WebGPU 캔버스 디바이스가 1초 안에 유실된다**. three.js 없이 순수 WebGPU clear 루프만으로도 재현된다. 그래서 E2E와 스크린샷은 three의 **WebGL2 백엔드**(`?backend=webgl2`)로 찍었다. 물리·워커·WASM은 백엔드와 무관하게 같다 | 헤드리스 WebGPU 검증 불가 | 실제 GPU 브라우저에서 확인 필요(사용자 PC 벤치) |
| W2 | three r186은 텍스처 뷰에 항상 `swizzle: 'rgba'`(항등)를 넘기는데, Chromium 141 이하는 이를 거부해 매 프레임이 실패한다. 항등 swizzle만 제거하는 호환 심(`web/src/render/webgpuCompat.ts`)을 넣었다(렌더 결과는 같다) | 구형 브라우저 호환 | three·브라우저가 갱신되면 제거 |
| W3 | WebGPU 디바이스가 유실되면 WebGL2 백엔드로 **페이지를 다시 연다**(시뮬레이션 상태는 사라진다) | 드문 GPU 리셋 시 상태 손실 | M5: 상태 스냅샷 복원 |

| W5 | M0 패널·HUD는 디버그 UI다. 디자인 시스템, 게임패드 포커스, 설정 화면은 M5 | UX | M5 (§18) |
