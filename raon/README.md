# 라온국어

국어 학원의 수업 일정, 보강, 출결, 선생님 피드백, 교재 진도를 한곳에서 관리하는 웹 서비스입니다.
선생님이 기록하면 학생과 학부모가 각자 자기 계정으로 들어와 바로 확인합니다.

## 무엇을 할 수 있나

**선생님 (원장 포함)**

- **오늘**: 오늘·내일 수업 시간표, 수업별 출석부(출석·지각·결석, "나머지 모두 출석"), 보강 대기 목록, 최근 피드백과 읽음 여부
- **달력**: 한 달 전체 일정. 전체 / 반별 / 학생별로 골라 보기. 날짜를 누르면 그날 수업과 출석부, 휴강 처리, 보강 잡기
- **학생**: 학생 등록(학생·학부모 계정을 함께 만들 수 있음), 학생별 일정 달력, 교재·진도, 피드백, 출결·보강, 계정 관리
- **보강**: 결석하거나 휴강한 수업이 자동으로 "보강 대기"에 모입니다. 보강을 잡으면 학생·학부모 달력에 바로 표시되고, 보강을 지우면 다시 대기로 돌아갑니다
- **피드백**: 한 번에 "학생에게"와 "학부모님께"를 따로 씁니다. 학생은 학생용 글만, 학부모는 학부모용 글만 봅니다. 누가 언제 읽었는지 표시됩니다
- **교재**: 교재 등록, 학생 또는 반 전체에 배정, 진도 기록(몇 강까지 했는지 + 진도 메모). 기록할 때마다 진도 이력이 남습니다
- **반·시간표**: 반마다 요일·시간을 정하면 달력에 정규 수업이 자동으로 채워집니다
- **설정**: 학원 정보, 선생님 계정 추가(원장 권한), 비밀번호 변경

**학생 · 학부모**

- **홈**: 다음 수업까지 남은 날과 시간, 앞으로 일주일 일정, 잡혀 있는 보강, 지금 공부하는 교재와 진도, 새 피드백, 이번 달 출결
- **일정**: 자기 수업만 보이는 달력 (정규 수업·보강·시험·휴강·휴원)
- **피드백**: 선생님이 자기에게 보낸 글만 편지 형태로 보입니다
- **교재**: 진행 중·예정·끝낸 교재와 최근 진도 기록
- 형제·자매가 함께 다니면 학부모 계정 하나로 아이를 바꿔 가며 볼 수 있습니다

학생·학부모 화면에는 다른 학생의 이름이 나오지 않습니다(반 보강이어도 자기 것만 보임).

## 처음 써 볼 때 (내 컴퓨터)

Node.js 22.5 이상이 필요합니다.

```bash
cd raon
npm install
npm run seed      # 예시 데이터 넣기 (선택)
npm run dev       # 서버(3000) + 화면(5173)
```

브라우저에서 http://localhost:5173 을 엽니다. 예시 데이터를 넣었다면 아래 계정으로 들어갈 수 있습니다. 비밀번호는 모두 `raon1234`입니다.

| 역할 | 아이디 |
| --- | --- |
| 원장 | `director` |
| 선생님 | `seojun` |
| 학생 (김태윤, 고2) | `taeyun` |
| 학부모 (김태윤·김하늘 어머니) | `taeyun.mom` |

예시 데이터 없이 시작하면 첫 화면이 "처음 설정"으로 열리고, 거기서 원장 계정을 만듭니다.

## 실제 서비스로 올리기

데이터는 서버의 SQLite 파일 하나(`DATA_DIR/raon.db`)에 저장됩니다. 그래서 **디스크가 계속 유지되는 곳**에 올려야 합니다. 서버를 다시 띄울 때마다 디스크가 비는 무료 호스팅(예: 디스크 없는 Render 무료 요금제, Vercel 같은 서버리스)은 맞지 않습니다.

### 방법 1. Railway (가장 간단)

1. https://railway.app 에서 GitHub 저장소를 연결해 새 서비스를 만듭니다.
2. 서비스 설정에서 **Root Directory** 를 `raon` 으로 지정합니다. (Dockerfile 을 자동으로 찾습니다)
3. **Volume** 을 추가하고 마운트 경로를 `/data` 로 정합니다.
4. 환경 변수에 `TRUST_PROXY=1` 을 넣습니다.
5. **Networking → Generate Domain** 으로 주소를 받거나, 가지고 있는 도메인(예: `raonkorean.com`)을 연결합니다. HTTPS 는 자동으로 붙습니다.
6. 주소로 들어가서 "처음 설정"에서 원장 계정을 만듭니다.

### 방법 2. Fly.io

```bash
cd raon
fly launch --no-deploy            # 이름·지역(nrt 도쿄 / icn 서울 가능 시) 선택
fly volumes create raon_data --size 1
```

`fly.toml` 에 아래를 추가한 뒤 `fly deploy`:

```toml
[env]
  TRUST_PROXY = "1"

[mounts]
  source = "raon_data"
  destination = "/data"

[http_service]
  internal_port = 3000
  force_https = true
```

### 방법 3. 직접 가진 서버 (VPS)

```bash
cd raon
docker build -t raon .
docker run -d --name raon --restart unless-stopped \
  -p 3000:3000 -v /srv/raon-data:/data -e TRUST_PROXY=1 raon
```

앞단에 Caddy 나 Nginx 로 HTTPS 를 붙입니다. Caddy 라면 `Caddyfile` 한 줄이면 됩니다:

```
raonkorean.com {
  reverse_proxy localhost:3000
}
```

> 로그인 쿠키는 HTTPS 에서만 동작하도록 되어 있습니다. HTTPS 없이 http 로 시험만 해 볼 때는 `COOKIE_SECURE=0` 을 넣으세요.

### 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` (Docker: `/data`) | 데이터 파일과 백업이 저장되는 폴더 |
| `NODE_ENV` | (Docker: `production`) | `production` 이면 로그인 쿠키에 Secure 가 붙음 |
| `COOKIE_SECURE` | — | `0` 이면 http 에서도 로그인 가능 (시험용) |
| `TRUST_PROXY` | — | 호스팅 프록시 뒤라면 `1` |
| `BACKUP_DAYS` | `14` | 매일 백업을 며칠치 남길지. `0` 이면 끔 |
| `SEED_DEMO` | — | `1` 이면 데이터가 비어 있을 때 예시 데이터 넣기 |

## 백업

서버는 하루에 한 번 `DATA_DIR/backups/raon-날짜.db` 로 전체 데이터를 복사해 두고, 최근 14일치를 남깁니다.
되돌리려면 서버를 멈추고 원하는 백업 파일을 `DATA_DIR/raon.db` 로 바꿔 넣은 뒤 다시 켭니다. (같은 폴더의 `raon.db-wal`, `raon.db-shm` 은 지웁니다)

가끔은 백업 파일을 내 컴퓨터나 클라우드 드라이브에도 받아 두세요. 서버 디스크 자체가 망가지면 같은 디스크의 백업도 함께 사라집니다.

## 학원에서 처음 세팅하는 순서

1. **설정**에서 학원 전화번호·주소를 넣고, 다른 선생님이 있으면 계정을 만듭니다.
2. **반·시간표**에서 반을 만들고 요일·시간을 정합니다. 달력에 정규 수업이 바로 생깁니다.
3. **학생**에서 학생을 등록합니다. 이때 학생 계정과 학부모 계정을 같이 만들 수 있습니다. 아이디와 처음 비밀번호를 학생·학부모에게 알려 주세요. (각자 "비밀번호 바꾸기"에서 바꿀 수 있습니다)
4. **교재**에서 쓰는 교재를 등록하고 반이나 학생에게 배정합니다.
5. 수업 때는 **오늘**에서 출석을 체크하고, 결석이 생기면 바로 "보강 잡기"를 누릅니다.
6. 수업 후 **피드백 쓰기**로 학생에게, 학부모님께 따로 남깁니다. 학생 화면 → 교재 탭에서 진도를 기록합니다.

휴원(명절·정기 휴무)은 달력에서 "일정 추가 → 휴원"으로 넣으면 그날 모든 정규 수업이 쉬는 날로 표시됩니다. 한 반만 쉬면 달력에서 그 수업을 눌러 "이날 휴강"을 누릅니다.

## 보안

- 비밀번호는 scrypt 로 해시해서 저장합니다. 선생님도 비밀번호 원문은 볼 수 없고, 새로 만들어 줄 수만 있습니다.
- 로그인은 30일 유지되는 HttpOnly 쿠키를 씁니다. 다른 사이트에서 보낸 요청은 막습니다(SameSite + JSON 요청만 허용).
- 같은 아이디로 비밀번호를 8번 틀리면 5분 동안 로그인이 막힙니다.
- 학생·학부모는 자기(자녀) 데이터만 조회할 수 있고, 모든 접근은 서버에서 다시 확인합니다.

## 코드 구조

```
raon/
├─ server/
│  ├─ core/        서버 로직 (저장소·프레임워크와 무관한 순수 함수)
│  │  ├─ schema.ts     DB 구조
│  │  ├─ auth.ts       로그인·세션·권한·설정·선생님 계정
│  │  ├─ students.ts   학생·학생 계정·학부모 계정
│  │  ├─ groups.ts     반·주간 시간표
│  │  ├─ calendar.ts   일정 펼치기, 휴강·휴원, 보강, 출결
│  │  ├─ feedback.ts   피드백 (학생용/학부모용 분리, 읽음 표시)
│  │  ├─ books.ts      교재·배정·진도 기록
│  │  ├─ home.ts       선생님 대시보드, 학생·학부모 홈
│  │  ├─ seed.ts       예시 데이터
│  │  └─ core.test.ts  테스트
│  ├─ node/        Node 전용 (node:sqlite, scrypt)
│  └─ main.ts      웹 서버 (Express), 정적 파일, 백업
├─ shared/         서버·화면 공용 (날짜 계산, 데이터 타입, 조사 처리)
├─ src/            화면 (React)
│  ├─ pages/teacher, pages/family
│  ├─ components/  달력, 출석부, 교재 표지·진도 자, 편지 등
│  └─ styles/app.css
└─ demo/           미리보기 빌드 (서버 코드를 브라우저 안에서 sql.js 로 실행)
```

## 명령어

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 모드 (서버 + 화면, 고치면 바로 반영) |
| `npm run build` | 실제 서비스용 빌드 (`dist/`) |
| `npm start` | 빌드한 서버 실행 |
| `npm test` | 서버 로직 테스트 |
| `npm run seed` | 비어 있는 DB 에 예시 데이터 넣기 |
| `npm run build:demo` | 한 파일짜리 미리보기 만들기 (`dist-demo/raon-preview.html`) |
