# 라온국어 — 홍보 사이트

`raon.html` + `raon/`. **홍보만** 하는 한 장짜리 스크롤 사이트입니다. 문제
풀이나 학습 기능은 없습니다 — 그건 `index.html`(수 국어논술 앱)이 하는 일이고,
이 저장소의 그 부분은 그대로 둔 채 새로 만들었습니다.

```bash
npm run dev            # http://localhost:5173/raon.html
npm run build          # tsc --noEmit + vite build → dist/
npm run build:raon     # → su-raon.html (단일 파일, 외부 요청 0건)
```

## 이름에서 출발한 디자인

**라온**은 ‘즐겁다’를 뜻하는 중세 국어 형용사 **‘랍다’**에 관형사형 어미가
붙은 말입니다. 두시언해(1481)에 이미 나옵니다.

> 人生애 슬프며 **라온** 이리 서르 半만 ᄒᆞ니
> (인생에 슬픈 일과 즐거운 일이 서로 반씩이니)

옛 표기의 아래아(ᄒᆞ니)는 대부분의 기기에 폰트가 없어 깨지기 때문에 화면에는
오늘의 글자로 옮겨 싣고, 그 사실을 출처 줄에 적어 두었습니다.

이름이 밝은 말이라 화면도 밝습니다. 그리고 **동그라미**가 규칙입니다 —
로고의 ㅇ, 번호를 감싼 링, 제목을 감싸는 타원(밑줄이 아니라), 알약 버튼,
목록의 점. 수 국어논술이 먹과 원고지의 **사각형**으로 서 있는 것과 정확히
반대편에 세웠습니다.

| | 수 국어논술 | 라온국어 |
| --- | --- | --- |
| 바탕 | 먹(어두움) 우선 | 한지빛 크림, 밝음 고정 |
| 강조 | 첨삭 빨강 **밑줄** | 살구빛 **동그라미** |
| 형태 | 사각형 · 원고지 칸 | 원 · 알약 |
| 성격 | 엄정한 편집자 | 밝고 다정한 초대 |

## 3D는 두 사이트가 나눠 씁니다

엔진은 `shared/three/`를 그대로 쓰되 **글자만 갈아 끼웁니다.**

```ts
new Scene(canvas, 'glyph', { mark: '라온', word: '즐거운' });
scene.setTheme(false); // 종이 위에서는 먹으로. 가산 혼합은 밝은 바탕에서 사라집니다.
```

블록이 쌓아 올리는 마크는 **라온**, 그 아래 빛으로 적히는 말은 **즐거운** —
3D가 이름의 뜻을 그대로 옮겨 적습니다. 기본값은 수 국어논술의 `수 / 국어논술`
이라 기존 사이트는 한 줄도 바뀌지 않습니다.

두 글자 마크는 격자를 넓히되 **행을 줄입니다.** 넓히기만 하면 셀 수가 인스턴스
수를 넘어서고, 그러면 `fit()`이 마크를 솎아 내면서 획이 흩어집니다.

**히어로 밖에서는 3D를 종이 뒤로 물립니다.** 히어로의 빈 띠를 `setFocusEl()`로
넘겨 로고를 그 상자에 정확히 맞추고, 그 띠가 화면을 벗어나면 종이 한 장
(`--veil-a`)을 더 덮어 본문 위에 형상이 겹치지 않게 합니다. 홍보물은 읽히는
것이 먼저입니다.

## 움직임 (`raon/ui/`)

- `scroll.ts` — 스크롤 버스 하나. 모든 효과가 같은 상태를 읽어 프레임당 레이아웃
  측정을 한 번으로 줄입니다.
- `motion.ts` — 등장, 제목 한 글자씩, 숫자 카운터, 카드 기울기, 자석 버튼,
  상단 바 · 현재 섹션, **수업의 흐름**(가로 이동), **후기 띠**(스크롤 속도에
  따라 밀림).
- `form.ts` — 검증과 전화번호 자동 서식. 접수 화면까지 보여 주지만 **전송하지
  않는다고 화면에 적습니다.**

동작 최소화 설정(`prefers-reduced-motion`)에서는 등장·띠·기울기·자석이 모두
멈추고 내용만 남습니다.

## 교체해야 할 내용

**연락처 · 주소 · 수치 · 인물 · 후기는 전부 예시 데이터입니다.**

- 전화 · 주소 · 상담 시간 (`raon.html`의 `.info`)
- 원장 이름 — 현재 **정하윤 원장** (`raon.html`의 `.teacher`)
- 과정 시간표와 정원, 숫자 섹션의 수치
- 상담 폼은 **전송되지 않습니다.** `raon/ui/form.ts`의 submit 핸들러에 `fetch`를
  붙이면 연결됩니다.
